\section{Parameter Selection: From Diagnosis to a Feasible Operating Point}
\label{sec:params}

The FLPSI layer is parameterised by $(w,t,T)$. This section shows these cannot be chosen from an
assumed impostor model: at the naive Super-Bit code that understates the false-accept rate by three
orders of magnitude and hits a floor no threshold can cross, a fact about \emph{that code}, not the
protocol, since once the code is co-designed with the accept rule the same arithmetic yields a feasible,
verified operating point. The accept model and its FAR/FRR functionals are those of \S\ref{sec:design};
by Proposition~\ref{prop:np} thresholding the count is Neyman--Pearson optimal, which makes parameter
selection one-dimensional, and the Gaussian rule of Proposition~\ref{prop:tmin},
\begin{equation}
\label{eq:tmin}
T_{\min} \;\approx\; \frac{\bigl[\,z_\alpha\sqrt{q_i(1-q_i)} + z_\beta\sqrt{q_g(1-q_g)}\,\bigr]^2}
                            {(q_g - q_i)^2},
\end{equation}
is used throughout: $T$ is governed by the gap $q_g-q_i$, itself governed by the Hamming laws. Every
number below plugs the \emph{measured} laws into these expressions.

\subsection{Diagnosis: what an assumed impostor law costs}
\label{sec:diagnosis}

The naive design fixes $(w,t)=(14,2)$ under the assumption that impostor codes are uniform,
$H \sim \mathrm{Binomial}(128,\tfrac12)$, i.e.\ mean $64$ and $\sigma=5.66$. The Super-Bit bridge does
centre the mean correctly (measured impostor mean $64.05$), but its measured standard deviation is
$\sigma=20.11$, $3.6\times$ the assumed value at the same mean. No first-moment check would catch it.
This is the pathology Lemma~\ref{lem:jensen} predicts: $q(H)$ is convex, so any mean-preserving spread
of the impostor law strictly increases $q_i$, hence $T_{\min}$, hence communication. At $(w,t)=(14,2)$
the assumed uniform law reproduces the design-time false-accept rate of $2.954\times10^{-5}$ exactly;
against the \emph{measured} Super-Bit law the same expression gives $4.578\times10^{-2}$, a
$1{,}550\times$ gap between the assumed and the actual per-record error, explained entirely by the
excess variance.

\paragraph{The collision floor.} Since $q(0)=1$, a code with any zero-Hamming impostor pairs has a
per-record FAR floor no parameter choice can beat. Super-Bit's $2/1{,}438{,}800$ held-out
probe$\times$gallery collisions give $p_0 = 1.39\times10^{-6}$ (exact Poisson 95\% CI
$[1.68\times10^{-7}, 5.02\times10^{-6}]$), which alone contributes
$\mathrm{FAR}_{\text{query}}\approx6.9\times10^{-3}$ at $N=5{,}000$. By Corollary~\ref{cor:floor} this
is a coding question governed by the effective dimension $m_{\mathrm{eff}}$, not the nominal $d$, which
is why Super-Bit's $\sigma$ barely moves ($20.1 \to 18.1$) as $D:16\to64$ and why this section ends not
with a retuning sweep but with a different code: the fix is to shrink the impostor variance toward the
uniform floor $d/4$, and \S\ref{sec:fix} shows a code that does.

\subsection{Effective bits track the impostor variance}
\label{sec:effbits-params}

The Daugman estimator $m_{\mathrm{eff}} = d^2/(4\sigma^2)$ at balance~\cite{Daugman03}
(Eq.~\ref{eq:meff}) turns a measured impostor $\sigma$ into an effective code length, recovering
$m_{\mathrm{eff}}=d$ for the ideal uniform code ($\sigma=5.66$, $m_{\mathrm{eff}}=128$). Across the
three codes it rises with $\sigma$: Super-Bit $\sigma=20.11 \Rightarrow m_{\mathrm{eff}}\approx10$
(participation ratio $9.84$), R1 $\sigma=14.60 \Rightarrow \approx18$ (participation $13.6$), and R2
$\sigma=6.72 \Rightarrow 90.7$ (participation $84.6$), the two estimators agreeing throughout.
Super-Bit's $m_{\mathrm{eff}}\approx10$ is not a defect of the bridge but a consequence of coding a
16-dimensional embedding into $128$ correlated bits: the bridge is faithful to the embedding's angular
structure, and that structure is what has low effective dimension.

\subsection{The fix: co-designing the code raises the effective bits and closes the gap}
\label{sec:fix}

Corollary~\ref{cor:target} and Theorem~\ref{thm:relaxation} turn the diagnosis into a training
objective (balance and decorrelate the bits, i.e.\ minimise the impostor variance), which on the same
backend gives two successive codes whose impostor $\sigma$ moves toward the ideal $5.66$
($20.11 \to 14.60 \to 6.72$) and whose EER moves with it ($1.89\% \to 0.87\% \to 0.17\%$; full ladder
with CIs in Table~\ref{tab:acc}), both driving the collision floor to zero, so the diagnostic that
indicted Super-Bit now certifies the fix.

\paragraph{A feasible operating point.} Plugging the feature-head's measured $q_g, q_i$ into the
$T_{\min}$ rule~\eqref{eq:tmin} and rounding, feasible parameters at target TAR $\geq 95\%$, per-record
FAR $\leq 10^{-2}$ are $(w,t,T)=(6,3,18)$, an order of magnitude fewer sub-samples than Super-Bit's
$T=64$ because the tighter impostor law raises $q_g-q_i$. Against the closed-form prediction
$8.12\times10^{-3}$, the real \texttt{flash-psi} binary at $(6,3,18)$ gives real TAR $97.0\%$, FAR
$0.80\%$ ($8.02\times10^{-3}$), $\sim\!84$\,ms/query, certifying that the design rule transfers to the
co-designed code, not only the naive one.

\subsection{Communication follows the same variance that fixed accuracy}
\label{sec:comms}

Because online communication scales with $T$ (A4), the variance reduction that lowered EER lowers
bytes. Super-Bit has no feasible \emph{matched} operating point (no $(w,t,T)$ reaches per-record FAR
$\leq10^{-2}$), and its uncalibrated $T=64$ point costs $7953$\,KB per query at $N=5{,}000$. Between the
two codes that do have a matched point (TAR $\geq95\%$, per-record FAR $\leq10^{-2}$, $N=5{,}000$), R1 at
$(19,3,34)$ costs $4317$\,KB while R2 reaches the same target at $(6,3,18)$ for $2377$\,KB, a $45\%$
reduction. Only the like-for-like $-45\%$ between calibrated codes is the communication contribution;
$7953\to2377$\,KB is against an untuned baseline with no matched point. Parameters are thus read off the
measured impostor Hamming distribution of whichever code is deployed, and a better code is a strictly
better choice of $(w,t,T)$ for free.
