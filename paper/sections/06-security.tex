\section{Security Analysis}
\label{sec:security}

We work in the semi-honest model with static corruptions. Throughout, $\lambda$ and $\kappa$ are the
computational and statistical security parameters, $\mathbb{F}$ a field with $|\mathbb{F}| \ge
2^{\kappa + \log N}$. The deployed operating point is $(w,t,T) = (6,3,18)$ over $d=128$-bit codes
(\S\ref{sec:params}), and every concrete constant here is computed from that triple. We separate what
is \textbf{proven} (semi-honest simulation security of the protocol) from what is \textbf{proposed}
(the revocable transform of \S\ref{sec:transform} and the malicious sketch of \S\ref{sec:future}).
\S\ref{sec:atrest} then steps outside the semi-honest model, since the most serious weakness is not a
protocol weakness at all.

\subsection{Functionality and leakage}
\label{sec:functionality}

Prior work proves security for one client set against one labelled server set; NeuralPSI runs $N$
record instances sharing a receiver polynomial and a PRF key, so the composite object must be named
first. The functionality $\mathcal{F}_{\mathsf{NeuralPSI}}^{d,T,w,\theta}$ takes client input
$\xt \in \{0,1\}^d$ and server input $D=\{(\yt_i,\ell_i)\}_{i\in[N]}$ with a public mask family
$M=\{m_j\}$, $\|m_j\|_1=w$; it computes $S_i = \{ j : \xt \wedge m_j = \yt_i \wedge m_j\}$ and
$\mathsf{acc}(i) = [|S_i| \ge \theta]$, returns $\{(i,\ell_i) : \mathsf{acc}(i)\}$ to the client and
$\bot$ to the server. The output is a \emph{set}, so more than one label can be returned; the informal
``the client learns the label, or reject, and nothing else'' is the ideal, slightly stronger than what
is proven since the realisation also leaks the collision structure behind each accept, a gap captured
by $\mathcal{L}_{\mathsf{C}}$ below.

Acceptance depends on a pair only through which positions differ, and in distribution only through
$H = \|\xt \oplus \yt_i\|_1$, which is where every error rate in \S\ref{sec:params} comes from. The
functionality says nothing about authentication: no party but $\mathsf{C}$ learns anything, so a
relying party cannot act on the result directly (\S\ref{sec:whoauth}). We take $M$ public, the
conservative reading. \label{sec:leakage}The protocol realises $\mathcal{F}_{\mathsf{NeuralPSI}}$
augmented with leakage
\begin{equation}
\label{eq:leakC}
\mathcal{L}_{\mathsf{C}} = \bigl(N,\; \{(i, S_i) : |S_i| \ge \theta\}\bigr), \qquad
\mathcal{L}_{\mathsf{S}} = \bot .
\end{equation}
This is strictly more than ``the identity of the matched record'': the client learns which sub-samples
collided (and since $M$ is public, each $j \in S_i$ pins $w$ positions of $\yt_i$), plus $N$ and the
accept/reject bit per record; we quantify the consequences in \S\ref{sec:attacks}. Timing is unmodelled
(online cost is linear in $N$, so response time leaks $N$), and we recommend constant-time
reconstruction of $\mathsf{out}$ as a deployment control. The corrupt server learns nothing beyond
$\bot$: it is the mOPRF sender, never sees $\xt$ or a plaintext sub-sample, and its view is simulatable
from its own input, the basis for the irreversibility claim of \S\ref{sec:atrest}.

\subsection{Security theorem (proven)}

\begin{theorem}[Semi-honest security]
\label{thm:main}
Let $F$ be a PRF and instantiate the sub-protocols with a semi-honest masked OPRF and vector ring-OLE.
Then NeuralPSI securely realises $\mathcal{F}_{\mathsf{NeuralPSI}}^{d,T,w,\theta}$ with leakage
$(\mathcal{L}_{\mathsf{C}}, \mathcal{L}_{\mathsf{S}})$ against a semi-honest adversary statically
corrupting one party, with simulator advantage at most
\begin{equation}
\label{eq:bound}
\varepsilon \;\le\;
   \varepsilon_{\mathsf{mOPRF}} + \varepsilon_{\mathsf{VROLE}} + \varepsilon_{\mathsf{LPN}}
 + \underbrace{\varepsilon_{F}\bigl(q + T\!\cdot\!2^{w}\bigr)}_{\text{PRF, extended domain}}
 + \underbrace{\tfrac{N(2T+1)}{|\mathbb{F}|}}_{\text{statistical}} ,
\end{equation}
$q$ the adversary's query count. This covers the transcript, not wall-clock timing.
\end{theorem}

Two terms are easy to omit and both matter. The PRF term is charged $T\cdot2^{w}$ extra oracle queries,
not $q$ alone: each mask restricts the PRF input to a domain of size $2^{w}=64$, so the full table has
$T\cdot2^{w}=1152 \approx 2^{10.2}$ entries, three orders of magnitude below the $2^{20}$ of the earlier
$(14,64)$ point. This cuts both ways, tightening the bound here while cheapening the dictionary attack
of \S\ref{sec:attacks}(c). The statistical term is the price of the masking step ($\mathsf{H}_4$) and is
why $|\mathbb{F}|$ must track $N$.

The proof is a hybrid argument; the two simulators and full reductions are in the extended version. Its
load-bearing step $\mathsf{H}_4$ replaces each non-colliding masking term by a uniform element, valid
because the masking polynomial $R$ is uniform of degree $\le T$ and $|\{j : j\notin S_i\}| \le T \le
\deg R + 1$; the implementation sets $\deg R = T$, so this holds \emph{by construction} at every
operating point ($T=18$ included), and the re-tuning $T:64\to18$ moved $\deg R$ with $T$. All $N$
instances share one receiver polynomial and one PRF key, so $\mathsf{H}_2$ and $\mathsf{H}_4$ are
stated over the whole database under one union bound, where a per-record invocation of a
single-instance theorem would fail.

\subsection{The stored template is a bearer credential}
\label{sec:atrest}

Theorem~\ref{thm:main} covers the protocol and says nothing about data at rest, which is where this
design is weakest, strictly weaker than a homomorphic baseline whose stored vectors are encrypted under
a key the server never holds. Irreversibility \emph{in transit} is proven and is the protocol's, not
the binariser's: the server never observes $\xt$ or a plaintext sub-sample, so privacy in transit rests
on the FLPSI/mOPRF layer. We do \emph{not} claim the binariser is one-way. An earlier one-bit
compressed-sensing inversion argument holds only for the Super-Bit $128{\times}16$ linear map (an
$8\times$ over-determined system); the deployed quantiser is a trained head on a 512-dimensional PCA of
a 25{,}088-dimensional feature vector, where that argument does not transfer, and inverse-biometrics
attacks on learned codes apply in principle~\cite{GomezBarreroGalbally20}. This
does not weaken the protocol, since security does not rest on binariser irreversibility. But the stored
code is a working credential regardless: the server stores $(\yt_i,\ell_i)$ in the clear, and an
adversary who reads $\yt_i$ and submits it obtains $H=0$ and acceptance with probability $1$, no
inversion required, so a database breach is immediate total impersonation. This is why at-rest
compromise is out of scope (\S\ref{sec:threat}).

Against ISO/IEC 24745~\cite{ISO24745}, the deployed design stands as follows.
\emph{Irreversibility} is provided in transit by the FLPSI layer (proven) but not claimed at rest or
of the binariser alone, where the stored code is a bearer credential. \emph{Unlinkability} fails as
deployed, since fixed public constants give one finger the same code everywhere, and
\emph{renewability} fails, since no second independent code can be issued from the same finger. The
transform of \S\ref{sec:transform} is what would provide the latter two (and non-invertibility per
IoM, with caveats).

\subsection{A proposed revocable transform, and who is authenticated}
\label{sec:transform}

Everything here is \textbf{proposed}. A client-side per-enrolment XOR mask (server stores $\yt \oplus
r_u$) preserves Hamming distance exactly, so accuracy is unchanged and 16 bytes of client state buys
unlinkability and renewability, though not replay resistance. For non-invertibility, Index-of-Max /
Winner-Take-All hashing with a per-user seed~\cite{JinEtAl18} gives a revocable, seed-diversifiable
transform whose distance stays rank/Hamming-like; IoM is only partially non-invertible and has known
cryptanalyses~\cite{GhammamEtAl20}, so adopting it would mean re-running the $q(H)$ validation under
the transformed distance and measuring reconstruction, cross-seed linkability, and re-seeded
pseudo-independence, none of which is done. For the bearer-credential gap against a passive reader we
would add envelope encryption at rest (key in an HSM). We reject storing the mOPRF images
$\{F_k(\yt_i \wedge m_j)\}_j$: at $w=6$ the per-mask domain is 64 values, so anyone who can evaluate
$F_k$ inverts each image in 64 tries.

\paragraph{Who is authenticated.}\label{sec:whoauth} As specified, no relying party learns the outcome,
so $\mathcal{F}_{\mathsf{NeuralPSI}}$ is a private lookup, not authentication; the credential step of
\S\ref{sec:design} closes the gap for one MAC, one nonce, and 32 bytes (the nonce makes $\sigma$
non-replayable). A client cannot forge $\sigma$ without $\ell_i$, so system security reduces to
recovering \emph{some} $\ell_i$: a false accept is not one bad login but a permanent per-user
credential, which is why we treat the false-accept rate as a security parameter.

\subsection{Attacks at the deployed operating point}
\label{sec:attacks}

The negative baseline used $(14,64)$ with Super-Bit, where impersonation with an unrelated finger
succeeded near-certainly at every tested $N$. At $(6,3,18)$ the picture changes on two axes.
\emph{(a) Impersonation without search:} the real-crypto per-record FAR is $8.02\times10^{-3}$ (TAR
$97.0\%$), an order of magnitude below the baseline's $4.578\times10^{-2}$; with $\theta$-searched
multi-finger fusion, query-level false-accept at $N=5000$ falls below $10^{-2}$ at a 0.9\%
false-reject rate (3-of-3, model-derived from measured per-finger probabilities on 201 subjects; only
the per-record figure is a direct real-crypto measurement). \emph{(b) Template recovery:} each
$j \in S_i$ pins $w=6$ positions, so a query covers at most $T\cdot w = 108$ of 128 slots, well below
the earlier configuration's $\approx345$, so full recovery now needs several authentications rather than
one. \emph{(c) The mOPRF dictionary:} each mask gives only $w=6$ bits of per-sub-sample preimage
resistance, and a coupon-collector estimate ($2^{w}\ln 2^{w} \approx 266$ sessions) bounds coverage of
one mask's 64-entry table. This is the cost of the cheaper $w$; the mitigation is per-account and
per-relying-party rate limiting plus per-epoch rotation of $k$ and $M$. The residual is real (at
$N\ge10^5$ the per-record FAR compounds and rate limiting only bounds the enumeration advantage) but
far smaller than the baseline's near-certain first attempt.

\paragraph{Malicious security (future work).}\label{sec:future} The VOLE/OKVS backend has known malicious-secure
variants, the lowest-effort route for the matching
step~\cite{RindalSchoppmann21}, but these do nothing for input substitution: the
code is computed client-side in plaintext, so a malicious-secure protocol still matches an
attacker-chosen or replayed code, and fixing that needs liveness or sensor attestation, outside the
cryptographic model. A signed-template design with a zero-knowledge proof of code well-formedness would
address substitution cryptographically, but proving image-to-code extraction in zero knowledge is
impractical at this scale; we flag it as speculative.
