\begin{abstract}
Privacy-preserving fingerprint authentication is usually built on homomorphic encryption
(HE): the server matches over ciphertext, at the cost of a multi-server cluster, large
evaluation keys, and a score-revealing interface. We instead realise it as a lightweight
\emph{two-party} protocol: a CNN maps the fingerprint, in plaintext on the client, to a
128-bit code, and Fuzzy-Labelled Private Set Intersection (FLPSI) returns \emph{only} the
matched record's label. The accuracy of such a pipeline comes from the feature extractor,
not the cryptography, so the binariser -- the map from a continuous embedding to the binary
code the matcher consumes -- is the design's true lever. Our central result is that this
lever is shared: the FLPSI acceptance rule
$\Pr[\mathrm{Binom}(T,q(H)) \ge t]$, with $q(H)=\binom{d-H}{w}/\binom{d}{w}$, makes both the
error rate \emph{and} the online communication (which scales with the subsample count $T$)
functionals of the code's impostor-Hamming distribution. We prove that, among codes of mean
$d/2$, the communication- and error-optimal one is the balanced, bit-decorrelated code whose
impostor Hamming distribution approaches the maximum-entropy $\mathrm{Binom}(d,\tfrac12)$, and
that a quantization-aware learned binariser is a differentiable relaxation of that optimum.
We instantiate the objective with two binarisers on one 128-bit FLPSI backend. A training-free
metric-aware code fixes the geometry an LSH baseline mis-assumed, cutting equal-error rate (EER)
on held-out SOCOFing from $1.89\%$ to $0.87\%$; a quantization-aware feature-head then reaches
EER $\mathbf{0.17\%}$ (95\% CI $[0.06,0.26]$), collapses the impostor Hamming standard deviation
from $20.1$ to $6.72$ (ideal $5.66$), raises code utilisation from ${\sim}10$ to ${\sim}90$ of
$128$ bits, and reaches a feasible operating point at which a loose baseline code is infeasible.
We validate the operating point end-to-end through the real cryptographic binary
(real TAR $97.0\%$, FAR $0.80\%$, matching the closed-form model). Generality tests on PolyU and
FVC2002 confirm the predicted pattern: the impostor-distribution (hence communication) gain is
universal, while the large accuracy gain is conditioned on a corpus where the extractor leaves a
quantization gap. We give a semi-honest security analysis with simulators for both corruptions
and assess the design against ISO/IEC 24745.

\end{abstract}
