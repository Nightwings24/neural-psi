\begin{abstract}
Privacy-preserving fingerprint authentication is usually built on homomorphic encryption:
the server matches over ciphertext, paying for it with a multi-server cluster, large
evaluation keys, and a score-revealing interface. We take a different route and build it as a
two-party protocol. A CNN maps the fingerprint to a 128-bit code in plaintext on the client,
and Fuzzy-Labelled Private Set Intersection (FLPSI) returns only the matched record's label.
Accuracy in such a pipeline comes from the feature extractor, not the cryptography, which
makes the \emph{binariser} (the map from a continuous embedding to the binary code the matcher
consumes) the real design lever. Our central result is that this lever is shared. The FLPSI
acceptance rule $\Pr[\mathrm{Binom}(T,q(H)) \ge t]$, with $q(H)=\binom{d-H}{w}/\binom{d}{w}$,
makes the error rate and the online communication (which scales with the subsample count $T$)
two readings of the same statistic: the code's impostor-Hamming distribution. We prove that,
among codes of mean $d/2$, the code that minimises both is the balanced, bit-decorrelated one
whose impostor distribution approaches the maximum-entropy $\mathrm{Binom}(d,\tfrac12)$, and
that a quantization-aware learned binariser is a differentiable relaxation of that optimum.
We instantiate the objective with two binarisers on one 128-bit FLPSI backend. A training-free
metric-aware code fixes a geometry an LSH baseline mis-assumed, cutting equal-error rate (EER)
on held-out SOCOFing from $1.89\%$ to $0.87\%$; a quantization-aware feature head then reaches
EER $\mathbf{0.17\%}$ (95\% CI $[0.06,0.26]$), collapses the impostor Hamming standard deviation
from $20.1$ to $6.72$ (ideal $5.66$), and raises code utilisation from ${\sim}10$ to ${\sim}90$
of $128$ bits. We validate the operating point end to end through the real cryptographic binary
(TAR $97.0\%$, FAR $0.80\%$, matching the closed-form model) and cut online communication by
$45\%$ ($4317 \to 2377$\,KB at $N{=}5000$) on the same backend. Generality tests on PolyU and
FVC2002 confirm the predicted split: the impostor-distribution gain, hence the communication
gain, is universal, while the large accuracy gain is conditioned on a corpus where the extractor
leaves a quantization gap. We give a semi-honest security analysis with simulators for both
corruptions and assess the design against ISO/IEC 24745.

\keywords{Private set intersection \and Biometric template protection \and

\end{abstract}
