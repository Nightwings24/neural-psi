System architecture

Neural-PSI

Privacy-preserving fingerprint authentication: a neural encoder turns a print into a 128-bit code, and two parties decide "close enough" through Fuzzy-Labelled Private Set Intersection - the server learns only a label on a match, and neither side reveals its fingerprints.

contribution (binariser) module (learned / fixed) data / code object encoder reused (online / enrollment)

Public vs private. The CNN, PCA map and QAT-head weights are public (published, same for everyone). The fingerprints and the 128-bit codes are private: they never leave a party in the clear, and the protocol discloses only the matching label on a close-enough match - or ⊥ otherwise. Multi-finger fusion (not shown) runs several codes through the same matcher and accepts on a quorum.
